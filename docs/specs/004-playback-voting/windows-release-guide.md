# Guia operacional — Kaioke no Windows

1. Execute `npm run package` em um Windows atualizado e instale o pacote gerado.
2. Na primeira abertura, permita o Kaioke no Firewall do Windows para redes **privadas**. Não habilite redes públicas.
3. Conecte o computador host e os celulares à mesma Wi-Fi; abra uma sessão e leia o QR code em dois celulares.
4. Confirme que somente o computador host reproduz o áudio. Nos celulares, valide faixa atual, progresso e voto de pulo.
5. Durante o ensaio, teste entrada e saída de participantes, reconexão ao alternar o Wi-Fi, fim de música, pulo do host e erro de vídeo indisponível.
6. Antes da apresentação, reproduza uma música inteira, confira volume/saída de áudio do Windows e mantenha a janela do host aberta.
